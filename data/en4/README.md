EN4
---

Profile data from the EN4 dataset is used to derive the along-isobath bin-averaged climatology (`../../proc/alongisob_seasonal_EN4_200m.nc`), created by script `../../proc/02-binavgEN4_shfbrk.py`.

To create that file, a netCDF file named `en4profiles-NWES_all.nc` containing a subset of all available EN4 T/S profiles in the NWES' bounding box (1975-2024) should be placed in this directory. This file is generated by following these steps:

1) Download yearly EN4 files in the list contained in the file `EN.4.2.2.profiles.g10.download-list.txt`. _e.g._, using the `wget` command:

```
wget -i EN.4.2.2.profiles.g10.download-list.txt
```

2) Unzip all files by running the bash script `unzip_all_years.sh`. This will create twelve monthly netCDF files for each year.

```
bash unzip_all_years.sh
```

3) Run the python script `00-subset_en4-NWES.py` to subset the monthly EN4 profile profiles within the desired area. This will create subset files with names of the form `EN.4.2.2.f.profiles.g10.YYYYMM-NWES.nc`.

```
python 00-subset_en4-NWES.py
```

4) Run the python script `01-interpz_concat_en4.py` to interpolate the profiles to a regular vertical grid and derive Absolute Salinity and Conservative Temperature:

```
python 01-interpz_concat_en4.py
```
