EN4
---

Profile data from the EN4 dataset is used to derive the along-isobath bin-averaged climatology (`../../proc/alongisob_seasonal_EN4_200m.nc`).

To create that file, a netCDF file named `en4profiles-NWES_all.nc` containing a subset of all available EN4 T/S profiles in the NWES' bounding box (1975-2024) should be placed in this directory. This file is generated by following these steps:

1) Download yearly EN4 files in the list contained in the file `EN.4.2.2.profiles.g10.download-list.txt`. e.g., with the `wget` command:

```
wget -i EN.4.2.2.profiles.g10.download-list.txt
```

2) Unzip all files by running the bash script `unzip_all_years.sh`:

```
bash unzip_all_years.sh
```

3) Run the python script `00-subset_en4-NWES.py` to subset the global EN4 profile files to the desired area:

```
python 00-subset_en4-NWES.py
```

4) Run the python script `01-interpz_concat_en4.py` to interpolate the profiles to a regular vertical grid and derive Absolute Salinity and Conservative Temperature:

```
python 01-interpz_concat_en4.py
```
